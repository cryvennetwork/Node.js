# 🚀 Cryven Network Mining dApp

Selamat datang di **Cryven Network** – revolusi keuangan **dari komunitas untuk komunitas**.  
Proyek ini adalah dApp berbasis web & Node.js yang menggabungkan **mining sederhana + pendapatan iklan** untuk memperkuat ekosistem token komunitas.

---

## 🔥 Visi
Membangun jembatan keuangan baru di mana pendapatan iklan digital digunakan untuk:
- ✅ Distribusi reward ke komunitas
- ✅ Buyback & Burn token
- ✅ Menjaga kelangkaan & nilai jangka panjang

---

## 📊 Tokenomics
- **Nama Token**: Cryven (CRV)  
- **Total Supply**: 1,000,000,000 CRV  
- **Distribusi Awal**:
  - 60% → Reward Mining Komunitas  
  - 20% → Buyback & Burn dari Iklan  
  - 10% → Tim & Development  
  - 10% → Cadangan Ekosistem  

---

## ⚙️ Mekanisme Mining
1. Pengguna membuka aplikasi web / mobile mining.
2. Aplikasi menayangkan iklan (Ads).
3. Pendapatan iklan dikonversi menjadi pembelian token di market.
4. Token hasil buyback → sebagian didistribusikan ke miner, sebagian dibakar (burn).  
   
📌 Semakin banyak pengguna & traffic, semakin besar potensi reward + deflasi supply.
